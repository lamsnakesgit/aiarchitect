### ⚠️ Почему ссылка может не появляться сразу:
1.  **Проверь видимость (Public/Private):** Если твой репозиторий `aiarchitect` **Приватный (Private)**, то GitHub Pages на нем **ПЛАТНЫЙ**. Чтобы сайт работал бесплатно, зайди в **Settings** -> **Danger Zone** (внизу) -> **Change visibility** и сделай его **Public**.
2.  **Подожди 2-3 минуты:** После нажатия "Save" GitHub запускает процесс сборки.
3.  **Вкладка Actions:** Зайди сверху во вкладку **Actions**. Если там крутится желтый кружок "pages build and deployment", значит сайт еще собирается. Когда станет зеленым — ссылка появится.

### 🖱️ Если кнопка "Allow once" не нажимается:
Это системное окно безопасности macOS. Просто **скопируй ссылку ниже вручную** и вставь её в адресную строку твоего браузера (Chrome/Safari):
`https://github.com/lamsnakesgit/aiarchitect/settings/pages`

## Шаг 1: Активируй сайт на GitHub (Бесплатно)
1. Зайди в свой репозиторий: `https://github.com/lamsnakesgit/aiarchitect`.
2. Перейди во вкладку **Settings** (Настройки) -> **Pages**.
3. В разделе **Build and deployment** выбери:
   - Branch: **main**
   - Folder: **/(root)**
4. Нажми **Save**.
5. Через 1-2 минуты сверху появится ссылка типа `https://lamsnakesgit.github.io/aiarchitect/`. 
   **Это и есть твоя публичная ссылка!**

## Шаг 3: Чтобы заявки реально ПРИХОДИЛИ (Formspree)
Чтобы данные не просто "улетали в никуда", а падали тебе на почту:
1. Зайди на [Formspree.io](https://formspree.io/) и создай бесплатный аккаунт.
2. Создай новую форму (New Form) и скопируй **Endpoint URL** (типа `https://formspree.io/f/xbjnqkq`).
3. В файле `ai-architect-website/ai-viz.html` на строке 358 замени `action="#"` на свой URL:
   ```html
   <form class="contact-form" id="contactForm" action="ТВОЙ_URL" method="POST">
   ```
4. Сделай коммит и пуш (или просто напиши мне, я обновлю за тебя).
