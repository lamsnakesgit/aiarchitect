## ⚠️ Важное уточнение про WordPress (ОШИБКА НОВИЧКА)

Есть две версии WordPress, и это путает 90% людей:

1.  **WordPress.com (Сервис):** Это как Tilda. Они дают тебе хостинг и админку. 
    - **Проблема:** Чтобы загрузить свою Zip-тему или плагины, они требуют план **"Business"** (~$25/мес). Это дороже Тильды! 
2.  **WordPress.org (Движок):** Это бесплатный код. Ты покупаешь обычный хостинг (за $2-3 в месяц), устанавливаешь туда этот движок кнопкой — и там **всё бесплатно**. Любые темы и плагины ставятся без ограничений.

## 🚀 Пошаговый план: Запуск на WordPress (Бесплатно)

Этот путь позволит тебе использовать наш премиальный дизайн и собирать заявки, не платя никому, кроме хостинг-провайдера.

### Шаг 1: Подготовка
1. Установи WordPress на свой хостинг.
2. Зайди в админку -> **Плагины** -> **Добавить новый**.
3. Найди и установи:
   - **Elementor** (Free версия).
   - **WPForms** (Free версия) — для создания форм.

### Шаг 2: Создание страницы
1. **Страницы** -> **Добавить новую** -> Назови её «AI Visualization».
2. Нажми кнопку **«Редактировать в Elementor»**.
3. Справа в настройках страницы (иконка шестеренки внизу) выбери **Макет страницы: Elementor Canvas** (это уберет стандартную шапку/подвал и даст пустой лист).

### Шаг 3: Перенос дизайна (Бесплатно)
1. **Тексты и кнопки:** Просто бери виджеты «Заголовок», «Текст» и «Кнопка» и перетаскивай их. Копируй текст из нашего `ai-viz.html`.
2. **Наш Слайдер (Самое важное):**
   - Найди виджет **HTML**. Перетащи его на страницу.
   - Скопируй из моего файла участок кода от `<div class="ba-slider-container">` до закрывающего `</div>`.
   - Скопируй также стили (CSS) из секции `<style>` и оберни их в тег `<style>...</style>` прямо в этом же HTML виджете.
   - Не забудь добавить JS код слайдера из `script.js`, обернув его в `<script>...</script>`.

### Шаг 4: Настройка формы
1. Зайди в **WPForms** в админке WordPress.
2. Создай простую форму: Имя, Контакт, Сообщение.
3. Скопируй **Shortcode** (типа `[wpforms id="123"]`).
4. В Elementor перетащи виджет **Shortcode** и вставь туда этот код.
5. В настройках WPForms укажи свой email — туда будут приходить заявки.

### 🔗 Полезные ссылки:
- [Elementor Free](https://wordpress.org/plugins/elementor/) — конструктор.
- [WPForms Lite](https://wordpress.org/plugins/wpforms-lite/) — формы.
- [Formspree](https://formspree.io/) — альтернатива, если не хочешь настраивать WPForms (просто вставляешь URL в `action`).

## Вариант 1. Ты оставляешь сайт «в коде» (Static HTML)
*Это то, что у нас сейчас. Самый быстрый путь.*

### 🛠 Способ А: Formspree (Без n8n, 1 минута)
1. Зарегистрируйся на [formspree.io](https://formspree.io/).
2. Создай новую форму и получи **Action URL** (типа `https://formspree.io/f/mqkrbkq`).
3. В файле `ai-viz.html` замени `<form ...>` на:
   ```html
   <form action="ТВОЙ_URL" method="POST" class="contact-form">
   ```
4. **Готово!** Заявки будут падать тебе на почту.

### 🛠 Способ Б: n8n (Если нужны боты и CRM)
1. В n8n создай Workflow: `Webhook Node` -> `Telegram Node`.
2. Скопируй **Webhook URL** из первой ноды.
3. В `ai-viz.html` настрой отправку через JS (я подготовлю скрипт).

## Вариант 2. Ты переносишь сайт в Tilda
*Идеально, если хочешь менять тексты визуально.*

1. **Создаешь Zero Block:** Рисуешь дизайн своего лендинга.
2. **Нативная форма Тильды:** Просто добавляешь элемент "Form" в Zero Block.
3. **Подключение:** В настройках сайта в Тильде выбираешь "Telegram" или "Почта". 
4. **Слайдер:** Чтобы оставить наш премиальный слайдер «До/После», добавь блок **T123 (HTML)** и вставь туда только код слайдера.

## Вариант 3. Ты переносишь сайт в WordPress
*Самый гибкий и бесплатный путь.*

### 🛠 Способ А: Elementor FREE (Бесплатно)
- У Elementor есть **бесплатная версия**. Её вполне хватит, чтобы собрать красивый лендинг.
- Ты просто ставишь плагин, выбираешь «Пустой холст» и переносишь туда тексты и кнопки.
- Наш слайдер вставляется через виджет **HTML**.

### 🛠 Способ Б: Родной редактор WordPress (Gutenberg) — ПОЛНОСТЬЮ НАТИВНО
- Это встроенный редактор WP, он бесплатный и легкий.
- Ты добавляешь блоки: «Заголовок», «Абзац», «Кнопка».
- Для нашего слайдера используешь стандартный блок **«Произвольный HTML»**.
- **Плюс:** Сайт будет работать быстрее, чем на Elementor, и тебе не нужно ничего покупать.

### 🛠 Способ В: Создание своей темы (Самый «Нативный»)
Если ты не хочешь возиться с Elementor и хочешь, чтобы всё работало «из коробки»:
1. Скачай файл **`viz-theme.zip`**, который я подготовил.
2. В админке WordPress зайди в **Внешний вид** -> **Темы** -> **Добавить новую** -> **Загрузить тему**.
3. Выбери этот Zip-архив и нажми «Установить».
4. **Готово!** Твой сайт теперь полноценная тема WordPress. Тексты на главной странице можно будет править прямо в файле `front-page.php` через редактор тем, или я могу добавить тебе поля ACF (Advanced Custom Fields) позже.

## 🤖 Про «MCP сервер» и автоматизацию
MCP (Model Context Protocol) — это технология, которая позволяет мне (твоему AI-ассистенту) глубже взаимодействовать с твоими локальными файлами и инструментами. 
- Если ты хочешь, чтобы я **сам** развернул тебе WordPress на сервере или локально — я могу попробовать помочь с командами, если у тебя есть доступ. 
- Но «волшебной кнопки» импорта HTML в WP одним кликом не существует, обычно это делается через создание темы или плагины-конструкторы.
