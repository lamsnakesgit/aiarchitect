## 📋 СКРИПТ ЗВОНКА (универсальный)

```
1. Приветствие
   "Добрый день, [Имя]! Меня зовут [Имя], 
   занимаюсь автоматизацией для бизнеса."

2. Причина звонка
   "Звоню потому что увидел ваш [проект/компанию/блог],
   и у меня есть решение которое может быть полезно."

3. Краткое предложение (30 сек)
   "[Описание услуги] — это позволит вам 
   [выгода: сэкономить время / увеличить продажи / автоматизировать]"

4. Вопрос
   "Скажите, это актуально для вас сейчас?"

5. Если да → назначить встречу
   "Отлично! Давайте созвонимся на 15 минут, 
   покажу как это работает. Когда удобно?"

6. Если нет → оставить контакт
   "Понял, спасибо за время! 
   Оставлю контакт — напишите когда будет актуально."
```
