## 🎤 3. ПРОГРАММА ВЫСТУПЛЕНИЯ НА МЕРОПРИЯТИИ

### 3.1 Структура презентации (45-60 мин)

**Введение (5 мин)**
- [ ] Открытие (зацепка, вопрос, история)
- [ ] О себе (кратко, с доказательствами)
- [ ] Что получат слушатели

**Основная часть (35-40 мин)**
- [ ] **Блок 1:** Боль аудитории (проблема)
  - Описание проблемы
  - Почему это важно
  - Что будет, если не решить
  
- [ ] **Блок 2:** Решение (ваш метод/подход)
  - Что делать
  - Как это работает
  - Примеры и кейсы
  
- [ ] **Блок 3:** Доказательства
  - Кейсы клиентов
  - Результаты (до/после)
  - Отзывы

**Призыв к действию (10-15 мин)**
- [ ] Оффер с мероприятия (спецпредложение)
- [ ] Бонусы для тех, кто купит сегодня
- [ ] Четкая инструкция (что делать дальше)

### 3.2 Материалы для выступления
- [ ] Презентация (PowerPoint/Keynote)
- [ ] Раздаточные материалы (чек-листы, контакты)
- [ ] Промо-ролик (1-2 мин) — **REMOTION**
- [ ] QR-коды для быстрой связи

## 🪟 4. ОКНА ПРОДАЖ

### 4.1 На мероприятии
- [ ] **Во время выступления:** мягкие продажи (истории, кейсы)
- [ ] **После выступления:** оффер (ограниченное предложение)
- [ ] **Перерывы:** личное общение, нетворкинг

### 4.2 После мероприятия
- [ ] **День 1:** теплое письмо участникам (благодарность + напоминание об оффере)
- [ ] **День 3:** кейс или полезный контент
- [ ] **День 7:** повторный оффер (дедлайн)
- [ ] **День 14:** приглашение на бесплатный вебинар/консультацию

## 🌐 7. САЙТ / ЛЕНДИНГ

### 7.1 Структура главной страницы

1. **Hero Section**
   - Заголовок (УТП)
   - Подзаголовок (кому и для чего)
   - CTA кнопка (записаться/скачать лид-магнит)
   - Фото эксперта

2. **О себе**
   - Фото + краткая биография
   - Достижения (цифры, факты)
   - Доказательства (сертификаты, награды)

3. **Продукты/Услуги**
   - Описание каждого продукта
   - Цены
   - CTA (купить/узнать больше)

4. **Кейсы/Отзывы**
   - До/После
   - Отзывы клиентов (видео/текст)

5. **Контакты**
   - Форма обратной связи
   - Соцсети

## 🎬 8. РОЛИК С REMOTION

### 8.1 Что нужно для создания

**Технические требования:**
- Node.js (v16+)
- NPM или Yarn
- React (знание базовых принципов)
- Remotion установлен глобально или в проекте

**Установка Remotion:**
```bash
npx create-video@latest my-video
cd my-video
npm start
```

### 8.2 Типы роликов для мероприятия

#### Вариант 1: Промо-ролик (60 сек)
- [0-10 сек] Логотип + имя эксперта
- [10-30 сек] Ключевые результаты клиентов (цифры)
- [30-50 сек] Краткое описание услуг
- [50-60 сек] Призыв к действию (контакты)

#### Вариант 2: Кейс-ролик (90 сек)
- [0-15 сек] Проблема клиента
- [15-45 сек] Как вы помогли (процесс)
- [45-75 сек] Результаты (до/после)
- [75-90 сек] Отзыв клиента + CTA

#### Вариант 3: Отзывы-карусель (30-45 сек)
- Слайды с отзывами клиентов
- Фото клиентов
- Ключевые цитаты
- Контакты в конце

### 8.3 Контент для ролика
- [ ] Логотип (PNG с прозрачностью)
- [ ] Фото экспорта (высокое качество)
- [ ] Фото клиентов / скриншоты результатов
- [ ] Музыка (royalty-free)
- [ ] Текст (заголовки, цитаты)
