## 🎯 ЧТО ПРОДАВАТЬ (по скорости монетизации)

### 🚀 УРОВЕНЬ 1: Самые быстрые деньги (1-7 дней)

#### 1. Экспресс-консультации
- **Формат:** Zoom/Telegram 30-60 мин
- **Цена:** 3,000 - 15,000 ₽
- **Как продать:** Пост в соцсетях + личные сообщения
- **Цикл сделки:** 1-3 дня
- **Пример:** "Разберу ваш случай за 60 минут. Дам конкретный план действий."

#### 2. Платные диагностики
- **Формат:** Анализ + созвон
- **Цена:** 5,000 - 20,000 ₽
- **Как продать:** Лендинг + реклама
- **Цикл сделки:** 1-5 дней

#### 3. Мини-продукты (PDF, чек-листы с поддержкой)
- **Формат:** PDF + доступ в чат
- **Цена:** 990 - 3,990 ₽
- **Как продать:** Reels/Shorts → ссылка
- **Цикл сделки:** 0-1 день

- **Как продать:** Вебинар → запуск
- **Цикл сделки:** 7-14 дней

- **Формат:** 4-8 недель, группа 10-30 чел
- **Цена:** 30,000 - 80,000 ₽
- **Как продать:** Лендинг + email-воронка
- **Цикл сделки:** 7-21 день

#### 6. Готовые решения
- **Формат:** Шаблоны, скрипты, воронки
- **Цена:** 5,000 - 30,000 ₽
- **Как продать:** Демо + продажа
- **Цикл сделки:** 3-7 дней

---

### 🏆 УРОВЕНЬ 3: Высокие чеки (1-3 месяца)

- **Формат:** 1-на-1, 1-3 месяца

- **Цикл сделки:** 14-30 дней

#### 8. Корпоративные тренинги
- **Формат:** Для команд компаний

- **Как продать:** LinkedIn + B2B продажи
- **Цикл сделки:** 30-90 дней

#### 9. Лицензии / Франшизы
- **Формат:** Право использовать вашу методологию
- **Цена:** 200,000 - 2,000,000 ₽
- **Как продать:** Личные продажи
- **Цикл сделки:** 60-180 дней

## 🎣 КОМУ ПРОДАВАТЬ (целевые сегменты)

### Сегмент A: "Горящие" клиенты (быстрые деньги)
- **Кто:** Люди с острой проблемой СЕЙЧАС
- **Боль:** Срочно нужно решение
- **Готовность платить:** Высокая
- **Как найти:** Комментарии, вопросы в тематических чатах
- **Продукты:** Консультации, экспресс-решения

### Сегмент B: "Осознанные" клиенты
- **Кто:** Понимают проблему, ищут решение
- **Боль:** Хотят изменений, но не знают как
- **Готовность платить:** Средняя-высокая
- **Как найти:** Подписчики конкурентов, тематические сообщества
- **Продукты:** Курсы, программы, интенсивы

### Сегмент C: "Холодные" клиенты
- **Кто:** Не осознают проблему
- **Боль:** Не понимают, что им нужна помощь
- **Готовность платить:** Низкая (нужен прогрев)
- **Как найти:** Массовая аудитория (Reels, TikTok)
- **Продукты:** Контент → лид-магниты → прогрев

## 🔄 ЦИКЛЫ СДЕЛОК

### Быстрый цикл (1-7 дней)

```
День 0: Пост/Reels с проблемой
        ↓
День 1: Комментарии + личные сообщения
        ↓
День 2-3: Переписка/созвон (бесплатная диагностика)
        ↓
День 3-5: Оффер (платная консультация/мини-продукт)
        ↓
День 5-7: Оплата + работа
```

### Средний цикл (2-4 недели)

```
Неделя 1: Контент + лид-магнит (PDF, вебинар)
          ↓
Неделя 2: Email-серия (5-7 писем)
          ↓
Неделя 2-3: Вебинар / марафон / интенсив
          ↓
Неделя 3: Продажа основного продукта
          ↓
Неделя 4: Оплата + старт
```

### Длинный цикл (1-3 месяца)

```
Месяц 1: Контент-маркетинг (регулярно)
         ↓
Месяц 1-2: Прогрев (кейсы, истории, результаты)
         ↓
Месяц 2: Заявки на созвон
         ↓
Месяц 2-3: Продажи 1-на-1 (созвоны)
         ↓
Месяц 3: Начало работы
```

**Каналы:**
- [ ] Instagram Reels (3-5 видео)

### Шаг 2: Захват контакта (0-1 день)

**Лид-магниты:**
- [ ] Бесплатный чек-лист
- [ ] Мини-консультация (15 мин)
- [ ] PDF-гайд
- [ ] Доступ в закрытый канал

**Инструменты:**
- Форма на лендинге → n8n → CRM (Notion)
- Telegram бот
- WhatsApp Business

### Шаг 3: Прогрев (1-3 дня)

**Email/Telegram:**
- Письмо 1: Благодарность + польза
- Письмо 2: Кейс клиента
- Письмо 3: Оффер с ограничением

### Шаг 4: Продажа (1-3 дня)

**Методы:**
- [ ] Созвон-диагностика → оффер
- [ ] Продающий вебинар (30-60 мин)
- [ ] Прямой оффер в переписке

**Офферы:**
- "Только 3 места до конца недели"
- "Скидка 30% первым 10 клиентам"
- "Бесплатный бонус при оплате сегодня"

## 📱 ИНТЕГРАЦИЯ С CRM (NOTION)

### Структура базы данных в Notion

**База: "Leads" (Лиды)**
| Поле | Тип | Описание |
|------|-----|----------|
| Имя | Text | ФИО клиента |
| Email | Email | Контакт |
| Телефон | Phone | Контакт |
| Источник | Select | Откуда пришел |
| Статус | Select | New/Contact/Offer/Sale/Lost |
| Продукт | Relation | Что интересует |
| Дата обращения | Date | Когда добавлен |
| Следующий шаг | Text | Что делать |
| Сумма | Number | Потенциальная сумма |

**База: "Продукты"**
| Поле | Тип |
|------|-----|
| Название | Text |
| Цена | Number |
| Тип | Select (Консультация/Курс/Наставничество) |
| Описание | Text |

**База: "Сделки"**
| Поле | Тип |
|------|-----|
| Клиент | Relation → Leads |
| Продукт | Relation → Продукты |
| Статус | Select (Переговоры/Оплачено/Завершено) |
| Сумма | Number |
| Дата оплаты | Date |

### Workflow: Форма → Notion (через n8n)

```
1. Webhook (форма с сайта)
   ↓
2. Notion MCP → Create page в базе "Leads"
   ↓
3. Telegram (уведомление вам)
   ↓
4. Email (автоответ клиенту)
```

**Команда для Notion MCP:**
```
Создай новую запись в базе Leads:
- Имя: {{name}}
- Email: {{email}}
- Телефон: {{phone}}
- Источник: Landing
- Статус: New
- Дата обращения: сегодня
```

## 💡 СОВЕТЫ ДЛЯ БЫСТРЫХ ДЕНЕГ

### ✅ Что работает:
1. **Личные продажи** - самый быстрый способ
2. **Низкий чек для старта** - легче продать
3. **Ограниченные офферы** - "только 3 места"
4. **Результаты клиентов** - лучший контент
5. **Быстрый ответ** - в течение 1 часа

### ❌ Что НЕ работает:
1. Ждать, пока придут клиенты
2. Продавать всем подряд
3. Сразу высокий чек без доверия
4. Сложные воронки без аудитории
5. Не собирать контакты
