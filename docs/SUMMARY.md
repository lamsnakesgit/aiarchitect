### Частые вопросы

**Q: С чего начать?**  
A: Откройте `docs/QUICK_START.md` и следуйте плану День 1.

**Q: Remotion обязателен?**  
A: Нет, это опционально. Можно обойтись без видео.

**Q: n8n обязателен?**  
A: Да, для захвата лидов с формы. Минимум 1 workflow нужен.

**Q: Сколько времени займет?**  
A: Базовая версия (лендинг + форма) - 1 день. Полная - 7 дней.

**Q: Можно ли использовать без кодинга?**  
A: Да, просто замените тексты в HTML. Для n8n кодинг не нужен.
